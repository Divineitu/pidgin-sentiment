# Nigerian Pidgin Tweet Sentiment

Sentiment classification (positive / negative / neutral) for Nigerian Pidgin tweets, using the
AfriSenti Pidgin data. Work in progress, full write-up coming.

## Quick start

```bash
pip install -r requirements.txt   # python 3.12
python src/prepare_data.py        # downloads and cleans the data
```

Then run the notebooks in order (`notebooks/01` to `05`). Notebook 04 needs a GPU (Colab/Kaggle).
